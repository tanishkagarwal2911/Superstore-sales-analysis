# Superstore Sales Analysis using SQL & Power BI

## Project Overview

This is an end-to-end data analytics project based on the Superstore dataset.
The project focuses on analysing sales, profit, customer behavior, and regional performance using SQL and Power BI. The objective was to transform raw business data into meaningful insights through SQL analysis and an interactive Power BI dashboard. 

## Problem Statement

Retail businesses generate large amounts of sales data every day, making it difficult to identify trends, profitable products, customer behavior, and regional performance through raw data alone.

The goal of this project was to analyze the Sample Superstore dataset using SQL and develop an interactive Power BI dashboard that helps stakeholders monitor KPIs, identify business opportunities, and make data-driven decisions.

1. Imported the Sample Superstore dataset.

## Business Insights

The business generated approximately ₹2M in total sales with ₹286K total profit.
The West region contributed the highest sales among all regions.
Technology was the most profitable category, while Furniture generated the lowest profit.
The Consumer segment was the largest contributor to sales.
The overall profit margin was 12.47%, indicating a healthy positive margin.
The business recorded approximately 5K orders from 793 customers.
Average Order Value was ₹458.61, providing an indication of average revenue generated per order.
Sales showed an overall upward trend from 2014 to 2017, with noticeable monthly fluctuations.

## Conclusion

This Superstore Sales Analysis provided an end-to-end view of sales, profitability, customer segments, product categories, and regional performance.

SQL was used to perform data analysis and extract meaningful business information, while Power BI was used to transform the analysis into an interactive dashboard.

The analysis identified the West region as the leading sales contributor, Technology as the most profitable category, and Consumer as the highest-performing customer segment. The findings also highlighted Furniture as an area requiring further profitability analysis.

Overall, the project demonstrates how SQL and Power BI can be combined to transform raw sales data into actionable business insights for better decision-making.
